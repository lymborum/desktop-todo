# 手帐 · 桌面悬浮待办

半透明、不挡视线、快到期才提醒你的桌面待办。手写笔记本风格，小巧，尽量利用每一块空间。

## 运行

```bash
cd todo-glass
npm install        # 若已装过可跳过
npm start
```

> 国内网络若 Electron 二进制下载失败，先设置镜像再安装：
> `set ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`

## 第一版功能

- **悬浮小卡片**：无边框、半透明、置顶、不占任务栏，默认停靠屏幕右侧
- **只在桌面出现（壁纸层）**：窗口挂在桌面壁纸那一层，打开网页 / 文件 / 全屏任何应用都会自然盖住它，回到桌面自动露出，全程不闪烁
- **第一眼只有待办**：日期一行 + 右上角 `＋`/`⋯` 小按钮 + 纯任务列表，无多余元素
- **快速添加**：点 `＋` 在列表顶部展开输入框，写一句回车即加；支持 `!` 标重要、「明天」「3天后」定日期；也可点小标签（⚑ 重要 / 今天 / 明天 / 3天后 / 每天 / 每周）
- **重要级**：每行一个小圆点，珊瑚红=高 / 芥末黄=中 / 鼠尾草绿=低
- **循环任务**：每天 / 每周，完成后划掉标「↻ 明天再来」，下个周期自动重现
- **钉住机制**（替代弹窗提醒）：任务**到期前 5 小时**起，卡片在贴边状态下**不会自动收起**，一直停在桌面，直到该任务完成（5 小时内、包括最后 3 小时都会钉住）。默认作息：一条"今天 23:00"截止的任务从 **18:00** 起钉住。头部显示 `◷ N`
- **"今天 / 明天 / 3天后"**：都按**当天 23:00 截止**算（今天 = 今晚 23 点）
- **两种模式（`⋯` 菜单「边框模式」开关切换）**：
  - **自由模式**：窗口在屏幕中随意拖动，不收起、不吸附
  - **边框模式**：手账一边始终贴住屏幕某条边（进入时自动贴到**最近的边**）；鼠标离开 → 自动**收进边框**只留一小条把手；**手账在前台时**鼠标移到边上 → 像**抽屉**一样抽出；可**沿着屏幕边框滑动**换位置
  - 在用其他应用（手账不在前台）时，鼠标划过边缘**不会自动弹出**，点一下小把手或按快捷键才会抽出，避免挡住正在看的网页 / 文件
  - 想换到另一条边：切回自由模式挪过去，再开边框模式
- 边框模式下，有到期不足 5 小时的任务时保持展开不收起
- **自动清理**：完成的一次性任务保留到当天结束，次日自动清除
- **删除保护**：悬停任务才浮现小 `✕`，不会误删
- **完成动画**：勾圈弹一下 + 对勾描边 + 任务平滑滑到列表底部

## 快捷键

| 快捷键 | 作用 |
|---|---|
| `Ctrl+Shift+D` | 呼出并聚焦添加框 |
| `Ctrl+Shift+H` | 隐藏 / 显示整个卡片 |

`⋯` 菜单：开机自启、退出；菜单底部分行列出快捷键与钉住规则说明。
点标签后焦点自动回到输入框，且添加框打开时在任意位置按回车都能直接添加。

## 技术

- **Electron**（Node 24，无边框 + `transparent` 半透明窗口；默认挂载到桌面壁纸层，打开其他应用 / 全屏时被自然盖住）
- 数据存本机：`%APPDATA%/glass-todo/tasks.json`，不联网
- 固定便利贴比例的窗口（300×340），形状不随内容变化，任务多了列表内部滚动

## 壁纸层工具（Windows）

`tools/fgcheck.exe` 输出当前前台窗口类名；`tools/pin-to-desktop.exe` 把手账窗口挂到桌面壁纸层（SetParent 到 WorkerW/Progman）。
已附带编译好的可执行文件；如需重新编译（Windows 自带 .NET Framework 的 csc）：

```bash
csc /nologo /out:tools\fgcheck.exe tools\fgcheck.cs
csc /nologo /out:tools\pin-to-desktop.exe tools\pin-to-desktop.cs
```

# 手帐 · 桌面悬浮待办（Desktop Todo）

一款 Windows 桌面悬浮待办应用：半透明手写笔记本风格，不挡视线，快到期才提醒。它像一张贴在桌面上的便利贴，随时瞄一眼，又不打扰你干活。

## ✨ 特点

- **只在桌面出现**：窗口挂在桌面壁纸层，打开网页、文件或全屏任何应用都会被自然盖住，回到桌面自动露出，全程不闪烁
- **不挡视线**：无边框、半透明，可收起成屏幕边缘一条小把手
- **快到期才提醒**：任务到期前 5 小时自动钉住卡片，直到你完成，不做打扰式弹窗
- **纯本地**：所有数据保存在本机，不联网、无账号、无广告

## 📦 安装

### 方式一：直接下载（推荐）

从 [Releases](../../releases/latest) 下载 Windows 便携版（单个 `.exe`），双击即用，无需安装。

### 方式二：从源码运行

需要 Node.js 20+：

```bash
npm install
npm start
```

> 国内网络若 Electron 二进制下载失败，先设置镜像再安装：
> `set ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`

## 🎯 功能

- **快速添加**：点 `＋` 展开输入框，写一句回车即加；支持 `!` 标重要、「今天 / 明天 / 3天后」自动定日期（按当天 23:00 截止），也可点小标签快速选择
- **重要级**：每行一个小圆点，珊瑚红=高 / 芥末黄=中 / 鼠尾草绿=低
- **循环任务**：每天 / 每周，完成后标「↻ 明天再来」，下个周期自动重现
- **钉住机制**（替代弹窗提醒）：任务到期前 5 小时起，卡片在贴边状态下不会自动收起，一直停在桌面直到完成；头部显示 `◷ N`
- **两种窗口模式**（`⋯` 菜单切换）：
  - **自由模式**：窗口可随意拖动
  - **边框模式**：贴住屏幕某条边，鼠标移开自动收成小把手，移回来像抽屉一样抽出；可沿边滑动换位置
- **自动清理**：完成的一次性任务保留到当天结束，次日自动清除
- **删除保护**：悬停任务才浮现 `✕`，不会误删
- **完成动画**：勾选描边，任务平滑滑到列表底部

## ⌨️ 快捷键

| 快捷键 | 作用 |
|---|---|
| `Ctrl+Shift+D` | 呼出并聚焦添加框 |
| `Ctrl+Shift+H` | 隐藏 / 显示整张卡片 |

`⋯` 菜单：开机自启、退出；菜单底部分行列出快捷键与钉住规则说明。

## 🔒 隐私

- 数据仅存本机 `%APPDATA%/glass-todo/tasks.json`
- 完全离线运行，不联网、不上传任何数据

## 🛠 技术

- Electron + 原生 HTML/CSS/JS，无后端
- 壁纸层通过 Win32 `SetParent` 挂载到 WorkerW/Progman（Windows 专用工具见 `tools/`，含源码与编译说明）
